# Third-party attribution & license gate

Rule (brief §3): record every model or library before adding it. MIT/Apache-2.0/BSD are preferred. AGPL/GPL, non-commercial and unclear licenses are not allowed. Ultralytics YOLO is deliberately **not** used.
